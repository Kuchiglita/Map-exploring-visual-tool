## Предлагаемая структура

```text
core/           # карты, агенты, состояния, действия, коллизии
geometry/       # конфигурационные пространства, сечения, геометрические свойства
solvers/        # точные и приближённые решатели
generators/     # карты, сценарии, контрпримеры
visualization/  # интерактивные инструменты
experiments/    # изолированные экспериментальные серии
tests/          # тесты и эталонные случаи
research/       # определения, литература, гипотезы, доказательства
```

Структура предварительная. Python предлагается для быстрого прототипирования; C++ — при необходимости ускорения. Выбор UI, форматов данных и зависимостей пока открыт.

## Инструменты из предыдущей работы

В отдельном геометрическом прототипе (архив endpoint_pair_classes_5x5.zip, не перенесён в данный репозиторий) использовались:

## Map Explorer v0.1

Открыть локальный dist/explorer.html. Каталог строится рекурсивно из maps/; путь можно изменить через --maps-dir, выходной файл через --out. Сборка: Python 3.10+, только стандартная библиотека. UI: HTML, CSS, JavaScript и Canvas, без CDN. Исходники в visualization/, dist/ — пересобираемый артефакт. Кроссплатформенность — обязательное требование; платформозависимые решения согласовываются заранее.

### Форматы

- .grid: прямоугольная ASCII-матрица из . (свободно) и # (стена), без заголовка. Связность не хранится.
- MovingAI .map: проверяются размеры; . G S считаются свободными, @ O T W — стенами. Это явная бинаризация для нашей модели, не сохранение семантики типов местности.
- .json: version=1, grid (массив строк) или map (имя файла из каталога), agents — массив объектов id, size, start, goal. Координаты [x,y], нулевые, x вправо, y вниз. size — положительная нечётная сторона; goal может быть null. Начальные тела не пересекаются; цели проверяются на статическую геометрию, взаимные пересечения целей разрешены (не утверждение о разрешимости). Импорт и сборка проверяют формат. Лимит карты — 1 000 000 клеток.

### Управление

Каталог: поиск, миниатюры, импорт файла/папки и drag-and-drop. Открыть карту как шаблон в редакторе. Изменения независимы от исходного файла. Стена/ластик — кисть, прямоугольник — заполнение стеной; размещение, перемещение и удаление агентов, назначение/снятие целей, undo/redo. Выбор агента кликом включает статическую эрозию для его размера; без агента размер выбирается в выпадающем списке «Карта эрозии» (1×1, 3×3, 5×5, 7×7, 9×9 или «Выключена»); выбор применяется сразу. Для агента большей стороны эрозия по клику продолжает работать, текущий размер отображается временной недоступной для ручного выбора опцией. Наведение показывает координаты и численный clearance. Компоненты и расстояния включаются отдельными кнопками. Расстояния — BFS по четырёхсвязному графу допустимых центров без других агентов. Esc сбрасывает выделение; колесо — zoom, drag правой/средней кнопкой или Space+левая — pan; в режиме выбора также обычный drag. F — вписать.

Скачать .grid или самодостаточный сценарий .json; вручную положить в maps/ и пересобрать каталог. Кнопка «В каталог сессии» добавляет копию временно, до перезагрузки HTML. Браузер не изменяет исходную папку автоматически. Встроенные карты random/warehouse и четыре minimap перенесены из LA-PIBT, ветка mp-occ200-20261123; demo — новый пример.

### Проверки

```bash
python -m unittest discover -s tests
node tests/geometry.test.js
node --check visualization/app.js
```

Node.js нужен только для тестов разработчика, не для просмотра/сборки. Геометрия: clearance по восьмисоседнему BFS от стен и внешней границы, компоненты и расстояния по четырёхсоседнему BFS. Слои не являются сертификатом совместной достижимости. Мосты, точки сочленения, классы сечений и точный поиск отложены.

### v0.1.1 — интерфейс редактора

Цвет определяется только размером агента: 1×1 #2a78d6, 3×3 #1baf7a, 5×5 #e39b0b, 7×7 #8a5cd6 (палитра старого LA-PIBT); для больших нечётных размеров детерминированный HSL. Цели и список используют тот же цвет, выделение — контур. В каталоге можно удалить любой элемент (в том числе встроенный), только из текущей сессии; исходные файлы не затрагиваются. Скачивание через верхнюю кнопку со стрелкой: карта (.grid) либо сценарий (.json). Редактор разделён на карту, общие инструменты, препятствия, агентов и цели. Undo/redo — стрелки в верхнем правом углу карты, Ctrl+Z / Ctrl+Shift+Z (раскладка не важна); в текстовых полях остаётся нативное редактирование.

## Exact solver baseline

См. [solvers/README.md](solvers/README.md). C++17/CMake, PM/RM, Visit/Stay, makespan/SOC; Joint BFS/Dijkstra, CBS, MC-CBS ASYM, прогресс JSONL, отдельный HTML replay. Статусы строго различают доказанную неразрешимость, ограниченный поиск и timeout. Запуск через Python-обёртку; никакой обязательной ОС.
