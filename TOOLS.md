# Tools

Реестр исследовательских инструментов. Обновляется при добавлении или изменении инструмента.

## Текущий статус

На 26.11.2026 в этом репозитории нет исполняемого кода. Команды запуска, зависимости и интерфейсы будут добавляться вместе с реализацией. Таблица ниже — проектируемый набор, а не список уже доступных возможностей.

## Планируемые инструменты

| Инструмент | Назначение | Статус |
|---|---|---|
| Map loader / editor | Загрузка, создание и редактирование решётчатых карт, препятствий и конфигураций | План |
| Configuration-space builder | Построение допустимых состояний и переходов для заданного footprint и модели движения | План |
| Geometry viewer | Визуализация эрозии, компонент связности, проходов, сечений и областей | План |
| Collision checker | Проверка пересечений тел, допустимости переходов и синхронного движения | План |
| Exact joint-state search | Полный поиск на малых экземплярах; достижимость, размен, кратчайшие по выбранной метрике решения, сертификаты | План |
| Cut classifier | Перечисление и классификация сечений по согласованному определению | Прототип вне репозитория |
| Counterexample generator | Перебор малых карт и начальных конфигураций для проверки гипотез | План |
| Simulation / replay | Воспроизведение траекторий, пошаговый просмотр и проверка состояния | План |
| Experiment runner | Воспроизводимые серии запусков, сбор метрик и результатов | План |

## Предлагаемая структура

```text
core/           # карты, агенты, состояния, действия, коллизии
geometry/       # конфигурационные пространства, сечения, геометрические свойства
solvers/        # точные и приближённые решатели
generators/     # карты, сценарии, контрпримеры
visualization/  # интерактивные инструменты
experiments/    # изолированные экспериментальные серии
tests/          # тесты и эталонные случаи
research/       # определения, литература, гипотезы, доказательства
```

Структура предварительная. Python предлагается для быстрого прототипирования; C++ — при необходимости ускорения. Выбор UI, форматов данных и зависимостей пока открыт.

## Инструменты из предыдущей работы

В отдельном геометрическом прототипе (архив endpoint_pair_classes_5x5.zip, не перенесён в данный репозиторий) использовались:

- enumerate_cuts.cpp — перечисление монотонных активных сечений и проверка BFS;
- factor_pairs.py — факторизация пар концов по граничным рёбрам, стягиваемость, экстремумы;
- make_viewer.py — независимая проверка и интерактивное HTML-представление;
- witnesses.py — сертификаты перемещений концов;
- run_all.sh — воспроизведение прототипа (C++17, Python 3, numpy, plotly).

Ограничения старого прототипа: связный граф допустимых центров, фиксированный размах R=5, квадратные агенты 5×5 для основной проверки. Перед переносом проверить допущения, тесты и обобщаемость.

## Правила регистрации инструмента

Для каждого реализованного инструмента здесь указывать путь, назначение, входные/выходные данные, ограничения модели, зависимости, точную команду запуска, минимальный пример и способ проверки.

Долгие серии запускать через GitHub Actions, когда соответствующий workflow будет реализован; не выдавать планируемые команды за рабочие.
