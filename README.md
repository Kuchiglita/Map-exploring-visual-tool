# LA-MAPF Research Sandbox

Исследовательская песочница для Large-Agent Multi-Agent Path Finding (LA-MAPF), в том числе lifelong-варианта и гетерогенных флотов.

## Цель

Исследовать геометрические, комбинаторные и динамические свойства LA-MAPF, выявлять ограничения достижимости и пропускной способности и на их основе разрабатывать методы планирования с обоснованной научной новизной.

В отличие от предыдущего проекта, здесь не предполагается заранее привязывать исследование к PIBT. PIBT, EPIBT, MD-PIBT и другие решатели рассматриваются как возможные baseline, инструменты экспериментов и объекты теоретического анализа.

## Основные вопросы

- Когда агенты конечного размера могут разъехаться или поменяться порядком?
- Как геометрия карты и размеры агентов определяют достижимость, узкие проходы и вместимость областей?
- Как оценить предельный throughput при заданной геометрии, составе флота и потоке задач?
- При каких условиях возникают пробки, потеря мобильности и starvation отдельных классов агентов?
- Какие ограничения присущи локальным планировщикам и какие механизмы позволяют их преодолеть?

## Принципы работы

- Отдельно фиксировать формальную постановку, доказанные утверждения, экспериментальные наблюдения и гипотезы.
- Проверять научную новизну по литературе до заявления о новом методе.
- Использовать точные решатели на малых экземплярах для поиска контрпримеров и проверки эвристик.
- Сохранять параметры экспериментов, версии кода, seed и определения метрик; учитывать отрицательные результаты.
- Не переносить автоматически предположения классического MAPF на LA-MAPF.
- Отделять исследовательскую геометрию от конкретного алгоритма планирования.

## Быстрый запуск

Откройте [dist/explorer.html](dist/explorer.html) локально в браузере (скачайте файл или клонируйте репозиторий). Сервер, интернет и установка библиотек не нужны.

Для обновления встроенного каталога после изменения maps/:

```bash
python visualization/build.py --maps-dir maps
```

Python 3.10+; команда и исходники одинаковы для Windows и Ubuntu. На Ubuntu при отсутствии алиаса python используйте python3. Подробности управления и форматов — [TOOLS.md](TOOLS.md).
